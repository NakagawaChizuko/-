第25次野尻湖湖底発掘 化石・遺物 入力フォーム（端末保存版）

この版は index.html 単体で起動できるようにしてあります。
（スマホの file:// 制約対策済み）
Safari/Chrome、Mac/Windowsで開きやすい汎用版です。
zip内のパスを英数字にし、古いSafari/Chromeで非対応になりやすいJavaScript構文を互換変換しています。
目安: Safari 9以降 / Chrome 49以降。
端末のSafariでlocalStorageが制限される場合でも、画面操作が止まらないように調整しています。

使い方（PC / スマホ共通）
1) zipを解凍
2) フォルダ内の index.html を開く

スマホで起動しない場合
- メール本文のプレビュー上ではなく、いったん「ファイル」へ保存してから開く
- iPhone: 共有 -> Safariで開く（または Chromeで開く）
- Android: ファイル管理アプリから index.html を Chrome で開く

注意
- 保存先は各端末のブラウザ内（端末ごとに別データ）
- ブラウザのサイトデータ削除で消える場合あり
- 端末間の自動同期なし
- Safariで「端末内保存が制限されています」と表示された場合は、出力タブからJSON保存してください
