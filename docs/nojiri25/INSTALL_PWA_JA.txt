第25次 化石・遺物 入力フォーム PWA登録手順

目的
- 最初だけインターネットまたはWi-Fi環境でGitHub Pagesのリンクを開きます。
- iPhone/iPadではSafariで「ホーム画面に追加」します。
- 追加後は、ホーム画面のアイコンからネットなしで起動できます。
- 入力データは端末内に保存されます。

登録URL
https://nakagawachizuko.github.io/-/nojiri25/

iPhone/iPadでの登録方法
1. Safariを開きます。
2. 上の登録URLを開きます。
3. 入力フォームが表示されたら、共有ボタンを押します。
4. 「ホーム画面に追加」を押します。
5. 名前を確認して「追加」を押します。
6. ホーム画面にできた「第25次入力」アイコンから起動します。

登録後の使い方
1. ホーム画面の「第25次入力」アイコンを押します。
2. 入力フォームが開きます。
3. ネットがない場所でも開けるか確認してください。
4. 1件入力して、アプリを閉じて、もう一度開いてデータが残るか確認してください。
5. 作業後は念のため「出力」タブからJSON保存してください。

注意
- iPhone/iPadではChromeではなくSafariで登録してください。
- 登録後はSafariでもChromeでもなく、ホーム画面のアイコンから起動してください。
- ブラウザのサイトデータ削除、履歴とWebサイトデータ削除、端末初期化をすると保存データが消えることがあります。
- 端末ごとに保存されます。別端末へ自動同期はされません。
